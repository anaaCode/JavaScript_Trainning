// (1) (a, b) => a + b

Task 2: pipe from Scratch

                    
What to do:

                    
    
                        
  • Implement pipe(...fns) that returns a function which runs its input through each fn left-to-right
    • 
                        
  • Create three small functions: addOne, square, negate
    • 
                        
  • Pipe them together and test with input 5 — expect -36
    • 
                    

                    
const pipe = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x);

const addOne = (x) => x + 1;
const square = (x) => x * x;
const negate = (x) => -x;

const transform = pipe(addOne, square, negate);
console.log(transform(5));   // -36
// addOne(5) → 6 → square(6) → 36 → negate(36) → -36

                    

                


                

                    
Task 3: Curry it

                    
What to do:

                    
    
                        
  • Write a curried volume(l)(w)(h) that returns l * w * h
    • 
                        
  • Pre-apply with l = 5 to get lengthOf5
    • 
                        
  • Pre-apply with w = 3 to get lengthOf5width3
    • 
                        
  • Call with h = 2 and verify the result is 30
    • 
                    

                    
const volume = (l) => (w) => (h) => l * w * h;

const lengthOf5       = volume(5);
const lengthOf5width3 = lengthOf5(3);
console.log(lengthOf5width3(2));   // 30

                    

                


                

                    
Bonus: Real Pipeline

                    
What to do: given the users array below, build a pipe pipeline using only small pure functions that:

                    
    
                        
  • Filters out anyone under 18
    • 
                        
  • Capitalises names
    • 
                        
  • Sorts by age descending
    • 
                        
  • Returns just the names
    • 
                    

                    
const users = [
  { name: "priya", age: 25 },
  { name: "aarav", age: 17 },
  { name: "riya",  age: 30 },
];

const filterAdults    = (arr) => arr.filter((u) => u.age >= 18);
const capitaliseNames = (arr) => arr.map((u) => ({ ...u, name: u.name[0].toUpperCase() + u.name.slice(1) }));
const sortByAgeDesc   = (arr) => [...arr].sort((a, b) => b.age - a.age);
const toNames         = (arr) => arr.map((u) => u.name);

const processUsers = pipe(filterAdults, capitaliseNames, sortByAgeDesc, toNames);
console.log(processUsers(users));   // ["Riya", "Priya"]
