Hands-on Tasks

Complete these tasks during class. Read each task fully before writing code. Open DevTools Console to see all output.

Task 1: Multiple Named Exports + Barrel

What to do:

  • Three files in js/math/: add.js, multiply.js, divide.js — each exports a named function
  • js/math/index.js is the barrel — it re-exports all three
  • hands-on.js imports all three from "./math/index.js" in a single line
// math/add.js
export function add(a, b) { return a + b; }

// math/multiply.js
export function multiply(a, b) { return a * b; }

// math/divide.js
export function divide(a, b) {
  if (b === 0) throw new Error("Cannot divide by zero");
  return a / b;
}

// math/index.js — barrel
export { add }      from "./add.js";
export { multiply } from "./multiply.js";
export { divide }   from "./divide.js";

// hands-on.js — single clean import
import { add, multiply, divide } from "./math/index.js";
console.log(add(3, 4));       // 7
console.log(multiply(3, 4));  // 12
console.log(divide(10, 2));   // 5

Check the Console — you should see 7, 12, 5 logged from the barrel import.

Task 2: Default + Named in the Same Import Statement

What to do:

  • Button.js has a default export function Button({label, onClick}) that creates a DOM button
  • It also has a named export const ButtonStyles = { ... }
  • Import both in one statement: import Button, { ButtonStyles } from "./Button.js"
// Button.js
export default function Button({ label, onClick }) { /* creates <button> */ }
export const ButtonStyles = { padding: "10px 20px", backgroundColor: "#1976D2", ... };

// hands-on.js
import Button, { ButtonStyles } from "./Button.js";
console.log(ButtonStyles);   // { padding: "10px 20px", ... }
// Renders a real button into #task2-output

Task 3: Dynamic import()

What to do:

  • heavy.js exports compute() returning "computed!"
  • loadAndRun() uses await import("./heavy.js") to load it on demand
  • Click the button below — watch the Console: heavy.js logs its evaluation message only after the click
// heavy.js
export function compute() { return "computed!"; }

// hands-on.js
async function loadAndRun() {
  const mod = await import("./heavy.js");   // fetched only now
  console.log(mod.compute());               // "computed!"
}

// Button click triggers the dynamic import
button.addEventListener("click", async () => {
  const { compute } = await import("./heavy.js");
  output.textContent = compute();
});

Bonus: Singleton Cache

What to do:

  • cache.js exports a single shared Map as default
  • userService.js imports cache and writes user objects keyed by user:id
  • productService.js imports cache and writes product objects keyed by product:id
  • hands-on.js imports cache directly — confirm both services' writes are visible
// cache.js
const cache = new Map();
export default cache;

// userService.js
import cache from "./cache.js";
export function saveUser(id, data) { cache.set(`user:${id}`, data); }

// productService.js
import cache from "./cache.js";
export function saveProduct(id, data) { cache.set(`product:${id}`, data); }

// hands-on.js
import cache from "./cache.js";
import { saveUser }    from "./userService.js";
import { saveProduct } from "./productService.js";

saveUser(1, { name: "Priya" });
saveProduct(42, { name: "Pen" });

console.log([...cache.entries()]);
// [["user:1", { name:"Priya" }], ["product:42", { name:"Pen" }]]
