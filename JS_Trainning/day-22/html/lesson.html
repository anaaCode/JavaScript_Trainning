Map / Set / WeakMap / WeakSet

JavaScript's built-in collections beyond plain objects and arrays — each designed for a specific job.

Topic 1: Map — Better Keyed Storage

Unlike objects, a Map accepts any value as a key, guarantees insertion-order iteration, and exposes a .size property directly.

const m = new Map();

m.set("name", "Priya");
m.set(42, "the answer");
m.set(true, "a boolean key");

const userObj = { id: 1 };
m.set(userObj, "value associated with userObj");  // object as key!

console.log(m.get("name"));   // "Priya"
console.log(m.get(userObj));  // "value associated with userObj"
console.log(m.size);          // 4
console.log(m.has(42));       // true
m.delete(42);

// Initialise from an array of pairs
const m2 = new Map([["a", 1], ["b", 2]]);
console.log(m2.get("a"));     // 1

// Iterate — preserves insertion order
for (const [key, value] of m2) {
  console.log(key, value);
}

Topic 2: Object ↔ Map Conversion

Object.entries() converts an object into a Map. Object.fromEntries() goes the other way. Map also has .keys(), .values(), and .entries() iterators.

const obj = { name: "Priya", city: "Jaipur" };

// Object → Map
const map = new Map(Object.entries(obj));
console.log(map.get("name"));  // "Priya"

// Map → Object (keys must be strings/symbols)
const back = Object.fromEntries(map);
console.log(back);  // { name: "Priya", city: "Jaipur" }

// Iteration helpers
for (const key of map.keys())   console.log("key:", key);
for (const val of map.values()) console.log("val:", val);
for (const [k, v] of map.entries()) console.log(k, "=", v);

// forEach — note: value comes FIRST
map.forEach((value, key) => console.log(key, "=", value));

Topic 3: Set — Unique Values

A Set stores only unique values. Adding a duplicate is silently ignored. The most common use is deduplicating an array in one line.

const s = new Set();
s.add("a");
s.add("b");
s.add("a");          // duplicate — ignored

console.log(s.size); // 2
console.log(s.has("a")); // true
s.delete("b");

// Initialise from array — duplicates removed automatically
const tags = new Set(["js", "react", "js", "node", "react"]);
console.log(tags.size);  // 3

// Deduplicate an array
const arr  = [1, 2, 2, 3, 4, 4, 5];
const uniq = [...new Set(arr)];
console.log(uniq);  // [1, 2, 3, 4, 5]

// Object identity — two separate objects are NOT equal
const set = new Set();
set.add({ id: 1 });
set.add({ id: 1 });  // different object reference → both kept
console.log(set.size);  // 2

Topic 4: Set Operations

Union, intersection, and difference are easily expressed with spread and .filter().

const a = new Set([1, 2, 3]);
const b = new Set([2, 3, 4]);

// Union — A ∪ B
const union = new Set([...a, ...b]);
console.log([...union]);  // [1, 2, 3, 4]

// Intersection — A ∩ B
const inter = new Set([...a].filter(x => b.has(x)));
console.log([...inter]);  // [2, 3]

// Difference — A − B
const diff = new Set([...a].filter(x => !b.has(x)));
console.log([...diff]);   // [1]

Topic 5: When Map/Set vs Object/Array

The right tool depends on what the keys are, whether uniqueness matters, and how often entries are added or removed.

// Cache keyed by an actual object reference — Map is the right pick
const cache = new Map();

function fetchWithCache(req) {
  if (cache.has(req)) return cache.get(req);  // hit
  const result = { data: "..." };             // simulate fetch
  cache.set(req, result);
  return result;
}

// Unique tag list from many posts — Set is the right pick
const posts = [
  { tags: ["js", "react"] },
  { tags: ["js", "node"] },
];
const allTags = new Set();
posts.forEach(p => p.tags.forEach(t => allTags.add(t)));
console.log([...allTags]);  // ["js", "react", "node"]

Topic 6: WeakMap & WeakSet

Weak collections hold weak references — they don't prevent garbage collection. Keys must be objects. They are not iterable and have no .size.

const wm = new WeakMap();
let user = { id: 1, name: "Priya" };

wm.set(user, { lastSeen: Date.now() });
console.log(wm.get(user));  // { lastSeen: ... }

user = null;
// The WeakMap entry is eventually GC'd — no memory leak.

// Practical: per-DOM-node metadata without leaks
const dataForElement = new WeakMap();
function attachData(el, data) { dataForElement.set(el, data); }
// When the element is removed from the DOM and has no other reference,
// the WeakMap entry is auto-cleaned.

// WeakSet — track object membership without preventing GC
const seen = new WeakSet();
function process(item) {
  if (seen.has(item)) return;  // skip already-processed
  seen.add(item);
  // ... do work
}
