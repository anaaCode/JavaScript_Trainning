Task 1: Build a Counter

What to do:

  • Write a function makeCounter() that returns a function
  • The returned function, each time called, returns the next integer starting from 1
  • Create two independent counters and verify they don't interfere
  • In a comment, explain where count lives between calls
function makeCounter() {
  let count = 0;
  return function () {
    count++;
    return count;
  };
}

const counter1 = makeCounter();
const counter2 = makeCounter();

console.log(counter1());  // 1
console.log(counter1());  // 2
console.log(counter2());  // 1 ← independent — its own count
console.log(counter1());  // 3

// count lives in the closure — inside makeCounter's scope.
// It persists between calls because the returned function holds a reference to it.
// Each makeCounter() call creates a SEPARATE closure with its own count.

Task 2: Fix the var-in-Loop Bug

What to do:

  • Type this snippet exactly, predict the output, then run it
  • Fix it by changing ONE keyword
  • In a comment, explain why var produced the surprising output
// Buggy version
for (var i = 1; i <= 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// Logs: 4, 4, 4  ← all callbacks share the same i, loop finished first

// Fixed — change var to let
for (let i = 1; i <= 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// Logs: 1, 2, 3

// var is function-scoped — ONE i shared by all iterations.
// By the time setTimeout fires, the loop is done and i is 4.
// let is block-scoped — each iteration gets a FRESH i.

Task 3: Private Bank Balance

What to do:

  • Write createAccount(initial) returning an object with deposit, withdraw, getBalance
  • balance must be private — not accessible as account.balance
  • Open account with 1000, deposit 500, withdraw 200, log the balance
  • Verify account.balance is undefined
function createAccount(initial) {
  let balance = initial;  // PRIVATE
  return {
    deposit:    (amt) => balance += amt,
    withdraw:   (amt) => balance -= amt,
    getBalance: ()    => balance,
  };
}

const account = createAccount(1000);
account.deposit(500);
account.withdraw(200);
console.log(account.getBalance());  // 1300
console.log(account.balance);       // undefined — truly private

Bonus: Build a Memoizer

What to do:

  • Write memoize(fn) that returns a new function caching results by argument
  • Wrap an expensiveSquare(n) that logs "computing..." and returns n * n
  • Call with 5 twice, then 10 once, then 5 again — note when the log fires
  • In a comment, explain where the cache lives
function memoize(fn) {
  const cache = {};
  return function (n) {
    if (n in cache) return cache[n];
    cache[n] = fn(n);
    return cache[n];
  };
}

const expensiveSquare = (n) => { console.log("computing..."); return n * n; };
const fastSquare = memoize(expensiveSquare);

console.log(fastSquare(5));   // computing... → 25
console.log(fastSquare(5));   // 25 (no log — from cache)
console.log(fastSquare(10));  // computing... → 100
console.log(fastSquare(5));   // 25 (no log — from cache)

// cache lives in the closure — inside memoize's scope.
// It persists across all calls to fastSquare because fastSquare closed over it.
