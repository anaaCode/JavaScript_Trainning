Homework

Practice tasks before the next class. Write each solution in your editor and verify the output in DevTools Console.

Exercise 1: once() for EventEmitter

Take createEmitter from hands-on and add a once(event, fn) method. It should register fn but auto-unsubscribe after the first emit — the callback fires exactly once, never again.

bus.once("boot", () => console.log("booted!"));
bus.emit("boot");   // booted!
bus.emit("boot");   // (nothing — already unsubscribed)

                


                

                    
Exercise 2: Cache with TTL

                    
Build a cacheFactory(ttlMs) that returns a cache where each entry expires after ttlMs milliseconds. get() should return undefined for expired entries.

                    
const cache = cacheFactory(500);
cache.set("token", "abc123");
console.log(cache.get("token"));   // "abc123"
// (after 500 ms)
console.log(cache.get("token"));   // undefined

                    

                


                

                    
Exercise 3: Array Debugging Proxy

                    
Wrap an array in a Proxy that logs every read, write, and delete. Use the get, set, and deleteProperty traps.

                    
const arr = debugArray([1, 2, 3]);
arr.push(4);    // [GET] push / [GET] length / [SET] 3 = 4 / [SET] length = 4
arr[0] = 99;    // [SET] 0 = 99
delete arr[2];  // [DELETE] 2

                    

                


                

                    
Exercise 4: React State and MVC / MVVM (Reading)

                    
Read about MVC and MVVM patterns, then write a short paragraph (3–5 sentences) in homework.js as a comment explaining how React's component state model relates to these patterns.

                    
Tip: React components sit somewhere between MVVM and Component-based architecture. The component is both View and ViewModel; the state is the Model; setState triggers re-render (the binding). There is no separate Controller; logic lives in the component or custom hooks.

                


                

                    
Bonus: Vue Reactivity Source

                    
Look at how Vue's reactivity system uses Proxy in their source: packages/reactivity/src/reactive.ts on GitHub. Write 2–3 observations about how their implementation differs from the simple reactive() we built in class.
