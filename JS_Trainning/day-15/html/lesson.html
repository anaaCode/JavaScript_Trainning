The this Keyword

this is a special keyword set at call time, not definition time. It refers to "the object that called this function".

Topic 1: What is this?

this is decided when a function is called, not when it is written. The same function can have a different this depending on how it is invoked.

function whoAmI() {
  console.log(this);
}

whoAmI();  // window/global (non-strict) OR undefined (strict)

const user = { name: "Priya", whoAmI };
user.whoAmI();  // logs the user object — called as a method

const other = { name: "Aarav", whoAmI };
other.whoAmI();  // logs other — same function, different this

Topic 2: The 4 Binding Rules

There are four rules that determine what this is. They are evaluated in order of priority.

// Rule 1 — Default: plain function call
function speak() { console.log(this); }
speak();  // undefined (strict) / global (non-strict)

// Rule 2 — Implicit: method call
const car = {
  brand: "Tata",
  show() { console.log(this.brand); },
};
car.show();  // "Tata"  ← this = car

// Rule 3 — Explicit: call / apply / bind (see Topic 3)

// Rule 4 — new: constructor binding
function User(name) { this.name = name; }
const p = new User("Anaya");
console.log(p.name);  // "Anaya"  ← this = the new object

// Predict these:
const obj = {
  n: 7,
  f() { return this.n; },
};
const g = obj.f;
console.log(obj.f());  // 7  — implicit binding, this = obj
console.log(g());      // undefined (strict) — default binding, this is lost

Topic 3: call / apply / bind

These three methods let you set this explicitly. The difference is when the function runs and how arguments are passed.

function greet(city, lang) {
  console.log(`${this.name} from ${city} speaks ${lang}`);
}
const u = { name: "Priya" };

// .call — invoke NOW, args listed one by one
greet.call(u, "Jaipur", "Hindi");     // "Priya from Jaipur speaks Hindi"

// .apply — invoke NOW, args as an array
greet.apply(u, ["Jaipur", "Hindi"]);  // "Priya from Jaipur speaks Hindi"

// .bind — returns a NEW function for later; args can be pre-set
const greetPriya = greet.bind(u, "Jaipur");
greetPriya("English");  // "Priya from Jaipur speaks English"
greetPriya("Marathi");  // "Priya from Jaipur speaks Marathi"

// Once bound, this CANNOT be re-bound
greetPriya.call({ name: "Aarav" }, "Tamil");
// still "Priya from Jaipur speaks Tamil"

Topic 4: Arrow Functions — Lexical this

Arrow functions have no own this. They inherit this from the enclosing scope at definition time. .call / .apply / .bind cannot change it.

const user = {
  name: "Priya",

  // Regular function — has its own this
  regular: function () {
    console.log(this.name);  // "Priya"
  },

  // Arrow — no own this; inherits from enclosing scope (module/global here)
  arrow: () => {
    console.log(this.name);  // undefined ← arrow as a method is usually wrong
  },
};

user.regular();  // "Priya"
user.arrow();    // undefined

// Where arrows SHINE: nested callbacks
const team = {
  members: ["Priya", "Aarav", "Riya"],
  greetAll() {
    // Arrow inherits 'this' from greetAll → which is 'team'
    this.members.forEach((m) => {
      console.log(`Hi ${m}, from team ${this.members.length}`);
    });
  },
};

team.greetAll();
// "Hi Priya, from team 3"
// "Hi Aarav, from team 3"
// "Hi Riya, from team 3"

Topic 5: this in Classes

In class methods, this works the same as implicit binding — it refers to the instance that called the method. The classic pitfall is detaching a method and calling it as a plain function.

class User {
  constructor(name) {
    this.name = name;  // this = the new instance
  }
  greet() {
    console.log(`Hi, I'm ${this.name}`);
  }
}

const a = new User("Priya");
const b = new User("Aarav");

a.greet();  // "Hi, I'm Priya"
b.greet();  // "Hi, I'm Aarav"

// Classic lost-this:
const greetFn = a.greet;
// greetFn();  // TypeError: cannot read 'name' of undefined
               // (this is now undefined in strict mode)

Topic 6: The "Lost this" Bug & Fixes

When a method is passed as a callback, it loses its this. There are three standard fixes.

class Counter {
  constructor() { this.count = 0; }
  inc() { this.count++; console.log(this.count); }
}

const c = new Counter();

// BUG — passed as plain function reference, this is lost
setTimeout(c.inc, 100);  // TypeError: cannot read 'count' of undefined

// FIX 1 — bind: permanently attach this
setTimeout(c.inc.bind(c), 100);  // works ✓

// FIX 2 — arrow wrapper: c.inc() is still called as a method
setTimeout(() => c.inc(), 100);  // works ✓

// FIX 3 — class field arrow: arrow's this is always the instance
class CounterArrow {
  count = 0;
  inc = () => { this.count++; console.log(this.count); };
}
const ca = new CounterArrow();
setTimeout(ca.inc, 100);  // works ✓

Topic 7: The Decision Tree

Walk these steps in order — the first matching rule wins.

// Step 1: Arrow function?       → this = outer scope's this
// Step 2: Called with new?      → this = the new object
// Step 3: .call / .apply / .bind?  → this = the explicit value
// Step 4: Called as obj.fn()?   → this = obj
// Step 5: Plain fn()?           → this = undefined (strict) / global

// Quick lookup:
// obj.method()              → this = obj
// const f = obj.m; f()      → this = undefined (strict)
// new Foo()                  → this = new instance
// () => this                 → this = outer this
// arr.forEach(regularFn)    → this = undefined (strict)
