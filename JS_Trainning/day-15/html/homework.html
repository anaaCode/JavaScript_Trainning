Exercise 1: Predict All Four Bindings

What to do:

  • Build user = { name: "Priya", greet() { console.log(this.name); } }
  • Call it three ways: user.greet(), const fn = user.greet; fn(), and user.greet.call({ name: "X" })
  • Predict each output before running
  • In a comment, name the binding rule used in each call
const user = {
  name: "Priya",
  greet() { console.log(this.name); },
};

user.greet();                        // "Priya"   — implicit binding (this = user)

const fn = user.greet;
fn();                                // undefined — default binding (this lost)

user.greet.call({ name: "X" });      // "X"       — explicit binding (.call sets this)

Exercise 2: Fix a Class Method Bug — Three Ways

What to do:

  • Take the Counter class below, pass c.inc to setTimeout, and observe the TypeError
  • Fix it three ways: .bind, arrow wrapper, and class field arrow
  • For each fix, add a comment explaining how it solves the problem
class Counter {
  constructor() { this.count = 0; }
  inc() { this.count++; console.log(this.count); }
}

const c = new Counter();

// FIX 1 — .bind
// inc.bind(c) returns a new function permanently bound to c
setTimeout(c.inc.bind(c), 100);   // logs 1

// FIX 2 — Arrow wrapper
// () => c.inc() calls inc as a method, so this = c naturally
setTimeout(() => c.inc(), 100);   // logs 1

// FIX 3 — Class field arrow
// Arrow's this is captured at construction time — always the instance
class CounterFixed {
  count = 0;
  inc = () => { this.count++; console.log(this.count); };
}
const cf = new CounterFixed();
setTimeout(cf.inc, 100);          // logs 1

Exercise 3: apply with Spread

What to do:

  • Write function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }
  • Call it using .apply with the array [1, 2, 3, 4, 5]
  • In a comment, explain when .apply is convenient vs. the spread operator
function sum(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}

const numbers = [1, 2, 3, 4, 5];

// .apply passes an array as individual arguments
console.log(sum.apply(null, numbers));   // 15
// null here because sum doesn't use 'this' — we only care about the args

// Modern equivalent using spread
console.log(sum(...numbers));            // 15

// When .apply shines:
// Before ES6 spread existed, .apply was the only way to unpack an array into
// individual args. Today, spread (...) is cleaner for most cases.
// .apply is still useful when you already have a reference to the function
// and need to set 'this' AND spread args in one step.

Exercise 4: Arrow Function and bind

What to do:

  • Write const f = () => console.log(this) at the top level of a module
  • Try to .bind({ x: 1 }) it and call the result
  • In a comment, explain what it logs and why .bind has no effect
const f = () => console.log(this);

const bound = f.bind({ x: 1 });
bound();
// Logs: undefined (in a module) or window (in non-strict browser global scope)
// NOT { x: 1 }

// Why .bind has no effect on an arrow:
// Arrow functions capture 'this' from their enclosing lexical scope at
// definition time. That binding is permanent — .call, .apply, and .bind
// are silently ignored. You get back a new function reference, but 'this'
// inside it is still the original outer scope's this.
