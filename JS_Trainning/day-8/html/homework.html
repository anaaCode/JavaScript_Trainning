Homework Exercises

Exercise 1: Book with Bracket Notation and Method

What to do:

  • Create an object book with properties: title, author, year, pages
  • Log the title using bracket notation with a variable key
  • Add a method summary() that returns the title, author and year using template literals and this

Exercise 2: Object.entries with forEach

What to do:

  • Use Object.entries() to get all key-value pairs
  • Use forEach() to print every property in "key: value" format

Exercise 3: Copy Object with Spread Operator

What to do:

  • Copy the book object using the spread operator
  • Modify the copy (change year and title)
  • Verify the original object is unchanged
